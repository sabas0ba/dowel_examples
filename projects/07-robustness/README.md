# 07-robustness — 壊れた入力に対する応答の形

[04-diagnostics](../04-diagnostics/) が見るのは「正しく診断される誤り」である。
構文としては通り、型検査や併合で落ちるものを並べてある。

ここで見るのはその手前、**診断を組み立てる前に壊れている入力**に対する応答である。
括弧の閉じ忘れ、他の記法との取り違え、素直でないバイト列、そして極端な大きさ。

見るのは診断の中身ではなく、応答の形の4つだけ。

| | 破れたときの現れ方 |
|---|---|
| 1. シグナルで死なない | 「マニフェストが誤っている」ではなく「道具が壊れた」として現れる |
| 2. 受理するか拒むかのどちらかである | 拒むべきものを受理すると、誤りが下流へ流れる |
| 3. 拒むなら、位置つきの診断を出す | どこを直せばよいかが伝わらない |
| 4. 返ってくる | CI が時間切れで落ち、原因が入力だと分からない |

これらは診断コードと違って一件も文書化されていない。にもかかわらず、
**破れたときの現れ方が最も悪い**。abort したビルドツールは、CI では
基盤の不調と区別がつかない。

## 構成

対象は `subject/` ひとつだけである。`expect.sh` がその `dowel.build` を
差し替えては `check` を掛ける。パッケージを事例ごとに作らないのは、
ここで変えたいのが**マニフェストの中身だけ**だからである。

| | |
|---|---|
| [`inputs/*.build`](inputs/) | 差し替える中身。`ok-` で始まるものは受理されるべきもの |
| [`subject/`](subject/) | 差し替え先。正しい `dowel.toml` と `src/main.c` を持つ |

符号化（BOM、CRLF、不正な UTF-8、NUL）と大きさに関わるものは
ファイルに置かず `expect.sh` が生成する。git と編集器を通ると形が変わり、
リポジトリに置いた時点で入力でなくなるためである。

## 何を固定するか

### 1. 利用者が書き間違える形

19 件。閉じ忘れ（引用符・角括弧・丸括弧・見出し・インラインテーブル・
ブロックコメント）、他の記法との取り違え（YAML の `:`、JSON、CMake、
C の `;`、`->` と `=>`）、区切りの落とし忘れ。

いずれも1回の実行で、非零・位置つきの診断として返る。

### 2. 受理されるべきもの

5 件。タブによる字下げ、`//` 行コメント、単引用符、呼び出しの末尾カンマ、
ブロックコメント。

拒む側だけを固定すると「厳しくしすぎた」退行が検出できない。
この 5 件が落ちるようになったとき、実在するマニフェストが読めなくなる。

### 3. 素直でないバイト列

CRLF は受理される。BOM は拒まれる（[F-011](../../docs/10-findings.md#f-011)）。
不正な UTF-8 と NUL は位置つきで拒まれる。

BOM と CRLF はどちらも Windows の編集器が黙って付けるものであり、
利用者が書いた覚えの無い違いである。片方だけが通る状態になっている。

### 4. 大きさと深さ

20 万要素の配列、10MB の文字列、20 万行のコメントは、いずれも 200ms 以内に
応答が返る。

深い入れ子は abort する（[F-010](../../docs/10-findings.md#f-010)）。
配列・インラインテーブル・関数呼び出しの3つの形すべてで、スタックが溢れて
`SIGABRT` になり、診断は1件も出ない。溢れる手前でも、応答が深さに対して
超線形になる。

手で 10 万段書く利用者はいない。この形が問題になるのは、マニフェストを
生成する道具と、編集のたびに未完成のマニフェストを解析する言語サーバである。

### 5. 誤りの取りこぼし

独立した3つの誤りが1回の実行でまとめて出る。1件で止まると、
利用者は直しては走らせるを繰り返すことになる。

## 検査の書き方

`probe` が対象を1回走らせ、応答の形を変数に記録する。判定はそれを読むだけで、
改めて dowel を走らせない。同じ入力に対する4つの性質を、
4回の実行ではなく1回の実行から判定する。

```sh
feed unclosed-paren      # inputs/unclosed-paren.build を置いて走らせる
survives                 # シグナルで死んでいない
refused                  # 非零で終わった（ただしシグナルでも時間切れでもない）
located                  # 位置を持つ診断が1件以上ある
answers                  # 上限時間内に返った
```

## この形で確かめられないもの

読み取り権限が無い場合。本スイートは CI では一般利用者、
手元では root として走ることがあり、`chmod 000` の意味が環境によって変わる。
環境で結果が変わる検査は、退行の記録として使えない。
