# 01-minimal — 最小のパッケージ

書けるうちで最も短いマニフェスト。依存も伝播ブロックも持たない。

```
[bin.hello]
sources = glob("src/*.c")
```

## 何を固定するか

1. **既定値だけで組める。** `[package]` の3項目と `sources` のみで
   実行ファイルができる。ツールチェーンの宣言も構成の指定も要らない
2. **構成ごとにビルドディレクトリが分かれる。** `--config=release` は
   `debug` の成果物を上書きしない。上書きすると、構成を切り替えるたびに
   全体が作り直しになる
3. **実行器を替えても結果が変わらない。** ninja で組んだものを direct が
   最新と判定し、逆も同じである。記録を共有しない実装だと、
   実行器を切り替えるたびに全体が走り直す
4. **direct 実行器だけで一から組める。** ninja が無い環境でも同じ成果物が
   得られる。アクション数（コンパイル1・リンク1）まで固定する
5. **パッケージを汚さない。** 成果物は `.dowel/` の下に入る。
   例外は `compile_commands.json` のみで、これは言語サーバのために置かれる
6. **test ターゲットが無くても `dowel test` は成功する。** 「0 件成功」は
   成功である。ここを失敗にすると、ライブラリだけのパッケージを
   CI に並べられない

## 実行ファイルの出力

```
hello
```
